# Domus Cut · instaladores

Aqui ficam só os instaladores do **Domus Cut**, o editor de vídeo dos assinantes da Mentoria Domus.
O código do app não fica neste repositório.

Para baixar, use a página oficial: https://mentoriadomus.com/domus-cut

O app pede o e-mail de uma assinatura ativa da Mentoria Domus para abrir.
